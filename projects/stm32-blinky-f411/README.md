# stm32-blinky-f411

STM32CubeF4 HAL blinky (example blinky-f411). Generated by `mcu/clion/mcu-ide new stm32 stm32-blinky-f411 ` (`mcu/clion/new-project`); the SDK
example was **copied** here, the SDK tree under `mcu/stm32` is never modified.

## Open in CLion
File > Open > `mcu/projects/stm32-blinky-f411` (this folder). CLion reads `.idea/cmake.xml` and loads three CMake
profiles; pick one in the toolbar:

| Profile | What it builds | Build dir |
|---|---|---|
| Debug | firmware (Debug run config uses this profile) | `$MCU_OUT_BASE/projects/stm32-blinky-f411/cmake-build-debug` |
| Release | firmware | `$MCU_OUT_BASE/projects/stm32-blinky-f411/cmake-build-release` |
| Host-Tests | `tests/` with the buildtools gcc + GoogleTest (CTest) | `$MCU_OUT_BASE/projects/stm32-blinky-f411/cmake-build-host-tests` |

Each profile's environment (PATH = the SDK's `env.sh` tools + `mcu/host/sysbin`, plus the SDK variables)
and CMake options live in `.idea/cmake.xml`; nothing is taken from the IDE's global toolchain except
CLion's bundled CMake. The Build button (Ctrl+F9) builds all targets of the active profile.

## Run configurations (`.run/`, folder in the run widget)
| Name | Type | Does |
|---|---|---|
| Build (mcu-ide) | Shell Script | `../../ide/clion/mcu-ide build . Debug`: the same configure + build from a shell |
| Flash | Shell Script | builds, then `mcu flash stm32 blackpill-f411 stm32-blinky-f411` on this project's output |
| Monitor | Shell Script (terminal) | `mcu monitor stm32` (serial console; edit the port in the script text) |
| Debug (OpenOCD + ST-Link) | Embedded GDB Server | starts `openocd`, loads the ELF with CLion's bundled GDB |
| Host tests | CTest | runs `tests/` (select the Host-Tests profile first) |

## Files
- `CMakeLists.txt`: firmware build; the `MCU_HOST_TESTS` block at the top switches to the host tests.
- `lib/ringbuf/`: example of target-independent code; `tests/test_ringbuf.cpp` tests it on the host.
- `mcu-project.json`: what `mcu-ide` needs (SDK, target, flash and debug settings). Edit it, then run
  `../../ide/clion/mcu-ide new ... --force` only if you want the run configs regenerated.
- Command line equivalents: `../../ide/clion/mcu-ide build|test|flash|monitor|gdbserver stm32-blinky-f411`.
