# ch32v003-blink

ch32fun blink for CH32V003 (make). Generated by `mcu/clion/mcu-ide new wch ch32v003-blink ch32v003 blink` (`mcu/clion/new-project`); the SDK
example was **copied** here, the SDK tree under `mcu/wch` is never modified.

## Open in CLion
File > Open > `mcu/projects/ch32v003-blink` (this folder). CLion reads `.idea/cmake.xml` and loads three CMake
profiles; pick one in the toolbar:

| Profile | What it builds | Build dir |
|---|---|---|
| Debug | firmware (Debug run config uses this profile) | `$MCU_OUT_BASE/projects/ch32v003-blink/cmake-build-debug` |
| Release | firmware | `$MCU_OUT_BASE/projects/ch32v003-blink/cmake-build-release` |
| Host-Tests | `tests/` with the buildtools gcc + GoogleTest (CTest) | `$MCU_OUT_BASE/projects/ch32v003-blink/cmake-build-host-tests` |

Each profile's environment (PATH = the SDK's `env.sh` tools + `mcu/host/sysbin`, plus the SDK variables)
and CMake options live in `.idea/cmake.xml`; nothing is taken from the IDE's global toolchain except
CLion's bundled CMake. The Build button (Ctrl+F9) builds target `firmware` (it runs the SDK's make; target `firmware-index` only feeds code insight).

## Run configurations (`.run/`, folder in the run widget)
| Name | Type | Does |
|---|---|---|
| Build (mcu-ide) | Shell Script | `../../ide/clion/mcu-ide build . Debug`: the same configure + build from a shell |
| Flash | Shell Script | builds, then `mcu flash wch ch32v003 blink` on this project's output |
| Monitor | Shell Script (terminal) | `mcu monitor wch` (serial console; edit the port in the script text) |
| Debug (minichlink GDB server (WCH-LinkE)) | Embedded GDB Server | starts `minichlink`, loads the ELF with CLion's bundled GDB |
| Host tests | CTest | runs `tests/` (select the Host-Tests profile first) |

## Files
- `CMakeLists.txt`: firmware build (thin CMake around the SDK's make); the `MCU_HOST_TESTS` block at the top switches to the host tests.
- `lib/ringbuf/`: example of target-independent code; `tests/test_ringbuf.cpp` tests it on the host.
- `mcu-project.json`: what `mcu-ide` needs (SDK, target, flash and debug settings). Edit it, then run
  `../../ide/clion/mcu-ide new ... --force` only if you want the run configs regenerated.
- Command line equivalents: `../../ide/clion/mcu-ide build|test|flash|monitor|gdbserver ch32v003-blink`.
