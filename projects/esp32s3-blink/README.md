# esp32s3-blink

ESP-IDF get-started/blink for esp32s3. Generated by `mcu/clion/mcu-ide new esp-idf esp32s3-blink esp32s3` (`mcu/clion/new-project`); the SDK
example was **copied** here, the SDK tree under `mcu/esp-idf` is never modified.

## Open in CLion
File > Open > `mcu/projects/esp32s3-blink` (this folder). CLion reads `.idea/cmake.xml` and loads three CMake
profiles; pick one in the toolbar:

| Profile | What it builds | Build dir |
|---|---|---|
| Debug | firmware | `$MCU_OUT_BASE/projects/esp32s3-blink/cmake-build-debug` |
| Release | firmware | `$MCU_OUT_BASE/projects/esp32s3-blink/cmake-build-release` |
| Host-Tests | `tests/` with the buildtools gcc + GoogleTest (CTest) | `$MCU_OUT_BASE/projects/esp32s3-blink/cmake-build-host-tests` |

Each profile's environment (PATH = the SDK's `env.sh` tools + `mcu/host/sysbin`, plus the SDK variables)
and CMake options live in `.idea/cmake.xml`; nothing is taken from the IDE's global toolchain except
CLion's bundled CMake. The Build button (Ctrl+F9) builds all targets of the active profile.

## Run configurations (`.run/`, folder in the run widget)
| Name | Type | Does |
|---|---|---|
| Build (mcu-ide) | Shell Script | `../../ide/clion/mcu-ide build . Debug`: the same configure + build from a shell |
| Flash | Shell Script | builds, then `mcu run esp-idf -- python -m esptool ... write-flash @flash_args` on this project's output |
| Monitor | Shell Script (terminal) | `mcu monitor esp-idf` (serial console; edit the port in the script text) |
| (no Debug config) | | Xtensa core: CLion's bundled GDB has no Xtensa support; use 'idf.py openocd' + xtensa-esp32s3-elf-gdb from the IDF tools (mcu shell esp-idf) |
| Host tests | CTest | runs `tests/` (select the Host-Tests profile first) |

## Files
- `CMakeLists.txt`: firmware build; the `MCU_HOST_TESTS` block at the top switches to the host tests.
- `lib/ringbuf/`: example of target-independent code; `tests/test_ringbuf.cpp` tests it on the host.
- `mcu-project.json`: what `mcu-ide` needs (SDK, target, flash and debug settings). Edit it, then run
  `../../ide/clion/mcu-ide new ... --force` only if you want the run configs regenerated.
- Command line equivalents: `../../ide/clion/mcu-ide build|test|flash|monitor|gdbserver esp32s3-blink`.
