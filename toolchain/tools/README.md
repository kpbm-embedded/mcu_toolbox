Use: `. env.sh` (PATH, LD_LIBRARY_PATH for libstlink, OPENOCD_SCRIPTS) or `../mcu run tools -- <cmd>`.
Probes: ST-LINK V2/V3 (st-flash, openocd, pyocd, probe-rs), J-Link clones (probe-rs/openocd), DAPLink (pyocd/probe-rs/openocd), WCH-Link/CH347 (openocd xPack has no wch fork; use wlink/minichlink in `wch/`).
## udev (needs root, not installed)
`sudo cp udev/*.rules /etc/udev/rules.d/ && sudo udevadm control --reload && sudo udevadm trigger`
Files: 49-stlink*.rules (stlink 1.9.0), 69-probe-rs.rules (official), 60-cmsis-dap, 99-jlink, 50-wch-link, 50-stm32-dfu.
Note: `pyocd pack install stm32f103c8tx` found nothing; `stm32f103c8` worked.

## Self-contained
env.sh sources `../host/env.sh`. The Arm GNU toolchain (`cc1`, `as`, `lto1`, gdb...) needed OS libzstd/libncursesw/liblzma: it now carries an `$ORIGIN` RUNPATH into `../host/lib` (zstd 1.5.7 built from the official tarball) and `../host/python` (gdb-py needs CPython 3.8). `tools/venv` no longer holds pip cmake/ninja (host ones are used). stlink is built with static libusb.

## Layout and updates
Versioned dirs behind stable symlinks (env.sh/bin/ only name the symlinks): `xpack-openocd -> xpack-openocd-<ver>`, `probe-rs -> probe-rs-<ver>` (`bin/probe-rs`, `cargo-flash`, `cargo-embed` link into it), `toolchains/arm-gnu-toolchain -> arm-gnu-toolchain-<rel>`.
`./mcu update tools` (MCU_YES=1 to apply) verifies sha256, installs side by side and flips; `./mcu rollback tools` flips back. xPack `X.Y.Z-N.1` tags are npm-only re-publishes: the Linux binary is the one from `-N` (same sha256), so 0.12.0-7.1 lives in `xpack-openocd-0.12.0-7.1/` from the -7 tarball.

Installed versions (generated by `mcu update`): see [VERSIONS.md](VERSIONS.md).
